# Third-party examples

The scenes in this folder are the example gallery of the Manim Community Edition documentation (`docs/source/examples.rst` in https://github.com/ManimCommunity/manim), released under the MIT License, copyright (c) the Manim Community Developers. The licence text is in `LICENSE-manim-community.txt` next to this file.

manimkit adds a header docstring (title, tags, scene, source) to each file for retrieval; the scene code is unchanged.
